# Gate A: モデル妥当性検証

実施日: 2026-06-13
判定対象: ROADMAP §10 Gate A 「Jimi の実データ20件以上を入れ、Message / Gathering 分離が不自然でないことを確認する」

## 1. 方法

合成データではなく **Jimi の実際の説教履歴** を用いた。Obsidian Vault の
`01_Project/説教/日曜説教/2024/`（49本）と 2026 の数本・祈祷会奨励から、各ノートの
`**聖書箇所**` `**説教日**` `**中心メッセージ**` と骨子の `主題`/`招詞`/`讃美` を抽出し、
v1.3.1 台帳形式の CSV（**53行**）へ変換。KX-020/021 の取り込みパイプラインで投入した。

実データには次の「モデルを試す」要素が自然に含まれていた:

- **同一説教を同日に別会場で**: 「イエス・キリストの福音」（マルコ1:14-15）を 05-26 に
  かもい・中山の2会場で。さらに同題を 04-28 にも語っている。
- **特別集会の連続セッション**: 07-25〜27 の「集会1〜4」。
- **同日に2説教**: 04-05 に2本。
- **多様な聖書箇所表記**: 「詩篇92篇」「1章14-15節」「4章14−21節（全角マイナス）」など。

## 3. モデル妥当性の評価 → 合格（要 Jimi 確認）

**Message / Gathering / Delivery の分離は実データに対して自然で、破綻しなかった。**
典型ケース（1説教=1礼拝）はそのまま 1:1:1 にきれいに収まり、年間の偏りを分析で可視化できる。
分離が「不自然」になる箇所は見つからなかった。むしろ分離があるからこそ、後述の多会場ケースを
正しく表現する「器」が用意されている。

## 4. 発見事項（モデルの欠陥ではなく、取り込み／パーサの改善余地）

### 4.1 「1説教・複数回（複数会場）」が取り込みで重複 Message になる（要相談）

「イエス・キリストの福音」は実際には **1つの説教を3回（本会堂04-28・かもい05-26・中山05-26）**
語ったもの。理想は **1 Message ＋ 3 Delivery（3 Gathering）**。しかしフラットな台帳は「この3行は
同じ Message」という関係を持てないため、取り込みは **3つの別 Message** を作る。
Dry Run は同一 fingerprint を「ファイル内の重複候補」として警告するので気付けるが、自動では畳めない
（legacy_id が別なので §5 の規則どおり別物として作成）。

→ モデル（DB）は 1 Message↔N Delivery を表現できる。不足しているのは (a) 取り込み後に
「複数 Message を1つに統合し、配信履歴を束ねる」操作、または (b) 取り込み時に
`日付以外が一致＝同一説教の別配信` と見なすヒューリスティック。プロダクト判断が要る。

**決定・対応済み（2026-06-13、Jimi 方針）**: 統合せず **1説教=1礼拝を維持** する。
同じ説教を別の場所で語るときは「多少手を入れる＝完全には同一でない」ため、**内容を複製した
独立した Message を作り、場所を変える**。メッセージ詳細に「別の場所でも語る（複製）」を実装
（題・聖書箇所・本文を複製し、新しい日時・会場の礼拝予定を作成。元は不変）。各 Message は
Delivery を1つだけ持つ運用を保つ。

### 4.2 Scripture パーサが実データの表記ゆれを取りこぼす（6/53）

| 原文                             | 問題                                                |
| -------------------------------- | --------------------------------------------------- |
| 詩篇 92篇                        | 「篇」を章として解釈しない（詩篇で頻出）            |
| 4章14−21節 / 40章1−11節          | 全角マイナス `−`(U+2212) を範囲記号として認識しない |
| 1ヨハネ 4章1-6番                 | 「番」（節の誤記）を解釈しない                      |
| 1章1-5, 14節                     | 非連続の節（1-5 と 14）に未対応                     |
| 詩篇44篇（参照：ローマ8:35〜39） | 括弧内の参照注記を含む                              |

「篇」と全角マイナスは Jimi の表記で頻出（詩篇講解）。優先度高。非連続節・括弧注記は低頻度。

**対応済み（2026-06-13）**: Scripture パーサに正規化を追加し、「篇」→章、全角マイナス(U+2212)、
「番」→節、括弧内注記の除去に対応。実 import の構造化箇所が **47→52/53** に改善。
残る1件「1章1-5, 14節」は非連続の複数箇所のため意図的に拒否（別箇所として分割入力を促す。
原文は migration_notes に保全）。`packages/scripture/test/parser.test.ts` に回帰テスト追加。
